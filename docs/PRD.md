# simp v2 产品范围

定位：追爱军师，帮助用户理解真实语境、表达真实意愿、选择下一步。成功不是把任何对象追到手，而是回答有据、归属正确、表达自然、边界清楚，且后续判断能被新事实修正。

已实现的 P0–P3：可靠输入和描述统计；事实/转述/判断/建议/行动/结果分离的本地记忆；迁移及完整恢复；轻量入口与全部原有模块切换。sweet/strategic/hybrid 只影响表达。未建档也能处理简单请求。

P4：长期表达习惯学习、用户改写反馈与独立 review 工作流。P5：完整 24 案例 × 3 组 × 3 次模型对照，实际宿主和安装验证，最终发布。当前不声明完成这些阶段。

验收依据见 evals/README.md、evals/rubric.md 及 tests。自动化测试覆盖数据/工具，不等同于模型行为评测。P3 提供人工走查样例与静态路由检查；独立模型运行结果单独登记。

## 实际测试

Windows，Python 3.12.14；`python -m pytest -q --cov=tools --cov-report=term-missing --cov-fail-under=85`：**200 passed，0 failed，行覆盖率 92.22%**。原有评分导向测试已替换为新语义测试，照片/GPS 纯函数测试保留；不能只用旧新测试数量比较覆盖面。运行摘要在 test-summary.json。

实际子进程验证：带中文和空格的目录，建档 → 解析/导入 → 回复统计 → 上下文读取 → 来源校验均通过。其他 CLI 分支用入口级测试覆盖。git diff --check 无空白错误。

CI 已配置 Windows/Linux Python 3.12 矩阵及 85% 覆盖率门槛；本报告的数字仅指本地 Windows 执行，远端 CI 以 GitHub checks 为准。当前机器没有可用 WSL 环境，未在本机冒称完成 Linux 测试。

## 评审发现并修复

- 用户纠正身份后，依赖旧映射的观察、判断、建议失效；重新导入原文可绑定已确认的新身份。unknown 角色也保留可修订映射。
- 已被用户直接撤回的观察不能通过再次导入旧文件自动恢复。
- 草稿和分析不更新真实互动数或最近互动时间；未知时间保持未知，重复同材料不制造进展。
- CSV 多行、UTF-8、跨时区和跨日聚类时间有专门验证；CLI 输出避免覆盖输入与当前档案。
- 迁移坏行保留、预览不创建锁或修改文件；每个维护中断均阻止正常读写，恢复前保存当前状态。
